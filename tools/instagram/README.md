# 블로그 그림 → 인스타그램 자동 업로드

네이버 블로그에 올린 개별인정원료 설명 그림을 인스타그램 게시물로 올리는 스크립트입니다.

## 준비 (최초 1회)

1. [Python](https://www.python.org/downloads/) 설치 (설치 시 "Add python.exe to PATH" 체크)
2. 이 `tools/instagram` 폴더를 PC에 내려받기

## 실행

- `upload.bat` 더블클릭
  → `C:\Users\kimsi\OneDrive\바탕 화면\네이버블로그` 폴더의 그림을 모두 올립니다.
- 올리기 전에 결과만 확인하려면 명령 프롬프트에서 `upload.bat --dry-run`을 실행하세요.
  → 폴더 안 `_instagram\`에 변환된 그림이 생깁니다.

## 동작

- 폴더 안 jpg/png/webp 이미지를 **파일명 순서**로 읽습니다.
  순서를 바꾸려면 파일명 앞에 `1_`, `2_`처럼 번호를 붙이세요.
- 각 그림을 비율 그대로 1080×1350(4:5) 흰 배경 가운데에 배치합니다.
  잘리는 부분은 없습니다.
- 여러 장이면 캐러셀 게시물 1개로 올립니다. 게시물을 따로 올리려면 `--separate`를 붙이세요.
- 캡션: 폴더에 `caption.txt`(UTF-8)가 있으면 그 내용을 쓰고, 없으면 실행 중에 입력받습니다.
- 로그인: 아이디와 비밀번호를 실행 중에 입력합니다. 2단계 인증 코드도 입력할 수 있습니다.
  세션은 `ig_session.json`에 저장되며 git에 올라가지 않습니다.

## 주의

- `instagrapi`는 비공식 라이브러리입니다. 짧은 시간에 여러 번 로그인하거나 업로드하면
  인스타그램이 보안 확인을 요청할 수 있습니다. 하루 몇 건 수준으로 사용하세요.
